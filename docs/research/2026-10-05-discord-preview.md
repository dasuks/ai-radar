**확인할 점:** 종료 가능일과 실제 종료는 다르다. 운영 변경 전 공식 표와 현재 API 응답을 함께 확인해야 한다.

## 02 AI 코딩 도구 · Windows Codex 컴퓨터 사용 후 화면이 안 꺼진다는 제보

컴퓨터 사용을 Esc로 중단한 뒤 보조 프로세스가 유휴 시간을 계속 갱신한다는 이슈가 올라왔다.

제보자는 Codex 앱 26.930.3930.0에서 자동화 취소 후에도 화면 절전이 작동하지 않는 상황을 설명했다. 모든 Windows 사용자에게 발생하거나 수정됐다는 확인은 없다.

**활용 예시 (가상 시나리오)**

노트북에서 자동화 작업을 취소했는데 화면이 계속 켜져 있다면, 같은 증상인지 이슈의 재현 조건을 비교할 수 있다.

**확인할 점:** 사용자 제보이며 원인과 해결 여부가 확정된 공식 공지는 아니다.

## 02 AI 코딩 도구 · Agent Artifacts: 에이전트 문서에 줄 단위 피드백

Markdown·HTML 문서를 링크로 공유하고, 줄별 댓글을 에이전트가 다시 읽는 작업 흐름을 제공한다.

오늘 확인한 스킬 카탈로그 추가 항목이다. 같은 URL에 문서를 갱신할 수 있어 초안 검토와 수정에 활용할 여지가 있다. 오늘 새로 출시됐다는 의미는 아니다.

**활용 예시 (가상 시나리오)**

공개 가능한 기능 명세 초안을 공유한 뒤 특정 문장의 댓글을 받아 다음 초안에 반영하는 과정을 생각해볼 수 있다.

**확인할 점:** 초기 도구이며 직접 검증하지 않았다. 공개 공유 기본값과 비공개 페이지 댓글 제한을 확인해야 한다.

## 03 에이전트 개발 · 스킬이 많아질수록 개발이 복잡해진다는 커뮤니티 논쟁

스킬을 계속 추가하는 방식이 오히려 유지보수 부담을 키운다는 토론이 주목받았다.

Reddit의 Claude Code 커뮤니티에서 스킬과 지침의 복잡성을 놓고 의견이 갈렸다. 모든 작업에 많은 규칙을 넣기보다 반복 작업에 필요한 작은 스킬부터 검토할 만한 질문이다.

**활용 예시 (가상 시나리오)**

코드 리뷰 때 늘 확인하는 항목만 작은 스킬로 정리하고, 리뷰 누락이 줄었는지 실제 결과를 비교할 수 있다.

**확인할 점:** 커뮤니티 의견이며 추천 수가 효과를 입증하지는 않는다. 찬반 의견을 함께 읽는 용도다.

## 06 평가·보안 · Supercov: 빠진 분기를 찾아 테스트를 보완하는 플러그인

기존 테스트의 커버리지를 확인하고, 놓친 분기에 집중해 테스트를 추가하는 흐름을 제공한다.

Claude Code와 Codex용 플러그인으로 소개된다. 테스트 추가 후 재실행과 변경 비교를 이어가는 방식이다. 오늘 카탈로그에서 발견한 도구이며 출시일로 단정하지 않는다.

**활용 예시 (가상 시나리오)**

로그인 테스트는 있지만 비밀번호 오류나 세션 만료 테스트가 없다면, 이런 분기의 테스트 보완을 검토할 수 있다.

**확인할 점:** 직접 실행해 검증하지 않았다. 커버리지 분석과 별개로 선택적 품질·보안 분석에는 TypeSafe API 키가 필요하다.
