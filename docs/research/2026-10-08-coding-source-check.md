확인 범위: 2026-10-06~08, 확인일 2026-10-08 KST. 공식 변경 기록에서 최근 항목 2건을 확인했다. 둘 다 10월 6일 발표이며, 10월 8일 신규 발표로 표현하면 안 된다. 검색 결과의 수집일과 실제 발표일을 구분했다.

## 1. Cursor: iPhone에서 로컬 에이전트 확인·응답

- **발표일:** 2026-10-06. 공식 페이지는 날짜만 제공하므로 정확한 KST 발표 시각은 미확인.
- **확인된 변화:** Cursor iOS 앱에서 내 컴퓨터의 로컬 에이전트 진행 상황을 보고 메시지를 보낼 수 있다. 같은 계정의 컴퓨터를 선택하고 데스크톱 앱에서 연결 요청을 승인한다. Enterprise 외에는 기본 활성화이며, Enterprise는 관리자가 켠다. [공식 변경 기록](https://cursor.com/changelog/remote-control-local-agents)
- **활용 의미(해석):** 긴 구현·테스트 작업을 맡긴 뒤 자리를 비워도 휴대폰으로 상태를 보고 추가 지시할 수 있다. 로컬 환경이 필요한 작업을 원격에서 이어 보는 용도다.
- **제약:** 실행은 계속 원래 컴퓨터에서 이뤄지므로 컴퓨터가 켜져 있고 인터넷에 연결되어 있어야 한다. 절전 방지 설정 사용 시 전원 연결과 열린 덮개가 필요하다. Cloud Agents는 필수가 아니다. Android 지원이나 컴퓨터 종료 후 실행 지속은 이 발표에서 확인되지 않는다. [공식 변경 기록](https://cursor.com/changelog/remote-control-local-agents)
- **판정:** 워크플로 변경으로 본문 채택 가치 높음. 생산성 증가 수치는 공개되지 않았다.
