# 내일부터 적용하는 수집·편집 방식

적용일: 2026-10-07. 기존 Discord 게시물은 수정하거나 다시 보내지 않는다.

## 무엇을 읽는가

- 기존 OpenAI·Google·Hugging Face·Simon Willison·Latent Space 피드와 Hacker News를 유지한다.
- Claude Code, Codex, Vercel AI SDK, OpenAI Agents SDK의 공식 릴리스 피드를 추가했다. 사전 공개 버전이라는 이유만으로 게시하지 않고, 실제 작업에 영향을 주는 변경을 고른다.
- Reddit의 ClaudeCode·codex·LocalLLaMA·MachineLearning 일간 인기 글을 합친 피드에서 최대 20건을 후보로 읽는다. 추천 수는 피드에 없으므로 만들지 않는다. 밈이나 막연한 불평을 그대로 옮기지 않고, 설명이 구체적인 도구·기술·사용 사례를 고른다.
- GitHub Trending의 전체 언어 일간·주간 목록을 공개 미러에서 읽고, 각 저장소의 README를 GitHub에서 직접 읽는다. 두 목록에 겹치는 저장소는 합치고, AI 관련 후보를 기존 분석·편집 단계에서 선별한다. README 내용이 같으면 순위만 바뀌었다고 매일 다시 후보로 올리지 않는다. 원문·README 링크를 보존하며, 이는 GitHub 전체 저장소의 정확한 순위를 계산하는 기능은 아니다.
- GitHub는 로그인 없이 수집한다. 미러가 48시간 넘게 갱신되지 않았거나 GitHub 읽기 제한에 걸리면 실패·부분 수집으로 표시한다. README는 최대 16,000자를 읽고, 한 실행에서 최대 25개 후보를 전달한다. README의 제작자 설명은 직접 실행해 검증한 성능과 구분한다. [구현 결정과 한계](adr/0012-github-trending-discovery.md)

Reddit RSS는 **2026-11-13 종료 예정**이다. 사용자가 이 제약을 확인하고 임시 연결을 선택했다. 종료 전 대안을 다시 검토해야 하며 현재 검증된 영구 대체 경로는 없다. [Reddit 공식 공지](https://www.reddit.com/r/modnews/comments/1wubgvt/continuing_our_infrastructure_updates_whats/)

## 글을 어떻게 쓰는가

독자가 낯선 용어와 딱딱한 문장 때문에 읽기 어렵다는 피드백을 반영한다. 무조건 짧게 줄이는 대신, 무엇이 달라졌고 실제로 무엇을 해주는지 자연스러운 한국어로 설명한다. 용어는 처음 나올 때 하는 일을 풀어 쓰고, 요약과 본문에서 같은 설명을 반복하지 않는다. 예시는 이해에 도움이 될 때만 **활용 예시**로 표시한다. 실제 제한이나 조건이 있을 때만 유의점을 붙인다.

기존 짧은 요약문뿐 아니라 저장된 원문·검증된 주장·근거를 읽는다. 공개된 출처의 실제 링크만 사용한다. 제작자의 주장, 사용자 경험, 공식 발표를 구분하며 추천 수가 품질이나 효과의 증거인 것처럼 쓰지 않는다. 수집 날짜와 출시 날짜도 구분한다. 00에는 그날 실제 게시된 모든 글의 요약과 상세 링크가 들어간다.

## Threads: 코드 추가, 인증 대기

`choi.openai`를 설정에 등록하고 공식 `profile_posts` API용 수집기를 추가했다. 현재 이 환경에 인증 토큰이 없어 실제 글 수집은 아직 불가능하다. 빠진 인증을 빈 결과나 성공으로 숨기지 않고 수집 실패/부분 수집으로 기록한다. 다른 출처의 발행은 계속한다.

연결하려면 Meta 개발자 앱에 Threads 사용 사례를 추가하고 계정을 인증해야 한다. 필요한 권한은 `threads_basic`, `threads_profile_discovery`를 기준으로 확인한다. 발급받은 사용자 토큰은 기존 로컬 `.env`에 `THREADS_ACCESS_TOKEN=...`으로 보관하며 채팅이나 추적 파일에는 넣지 않는다. 실제 토큰으로 `choi.openai`의 본문·날짜·링크를 읽는 검증이 끝나야 연결 완료로 판정한다.

**UNVERIFIED EXTERNAL CONSTRAINT:** 대상 계정 조회 허용 여부, 앱 심사/권한, 공식 API의 실제 응답과 페이지 이동, 장기 토큰 갱신. 인증된 읽기 요청으로 확인해야 한다. 인증 실패 시 앱 심사나 추가 권한이 필요할 수 있으므로 토큰 하나만 있으면 무조건 된다고 보장하지 않는다. [Meta 공식 요청 예시](https://www.postman.com/meta/threads/request/34203612-116161fc-75af-4a09-a972-66d6f64ddb10)

## 검증과 운영

기존 RSS 수집기로 공식 릴리스 4종 및 Reddit 피드를 실제 읽었다. 로컬 미리보기는 실제 문서에서 주장 추출과 Discord 편집을 실행했으며 Publisher를 호출하지 않았다. 기존 메시지 수·발행 기록을 유지한다. Windows 예약은 매일 00시(KST)이며 다음 예약부터 현재 코드를 사용한다. 품질은 매번 원문과 모델 출력에 따라 달라질 수 있으므로 미리보기와 독자 피드백으로 계속 확인한다.
